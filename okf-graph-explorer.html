OKF Graph Explorer — a single-file, dependency-free viewer for Open Knowledge Format bundles.

Revision

It renders Markdown concepts, their frontmatter (type, tags, status, description) and reference links as an interactive graph you can filter, pan and zoom.

  • Open a folder, or drag one onto the window. On a web server it auto-loads bundles/.
  • Choose a bundle with ?bundle=<name|path> (or ?start=).
  • Prefetch fewer levels with ?depth=N (default: all). A node with a dashed ring (page or attachment) has unloaded content — click it to load, then click again to preview.
  • Desktop: click a node to preview, double-click a directory to enter, scroll to zoom.
  • Touch: tap to preview or enter, drag to pan, pinch to zoom.

This tool was generated with AI assistance. Review it before relying on it.

OKF Graph Explorer

Single-file, dependency-free viewer for this knowledge bundle.

  • Served: on a static server (including GitHub Pages) it loads bundles/ automatically from bundles/index.md.
  • Pick a bundle with a URL parameter, for example ?bundle=acme_retail (a name, a folder path, or a start .md file).
  • Limit prefetch depth with ?depth=N (default: all levels); click a dotted node to load its next level, click again to preview.
  • Local file: click Open folder and choose a bundle directory, or drag it onto this window.
